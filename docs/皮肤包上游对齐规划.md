# 皮肤包上游对齐规划（Windows ← macOS v0.2.14）

> 依据：对上游 InterstellarSkin.swift（485 行）、InterstellarMotionLab.swift、VoyageSkin.swift、OdysseyMotion/OdysseyParticleScene.swift（584 行）及各页面消费点的逐行深读。所有数值带 path:line。
> 现状基线：4+1 轮已交付"板+veil+玻璃+光晕动效"骨架，终验 7/7。本规划覆盖剩余差距。
> 结论：上游不是"素材贴背景"，是一套**表面-角色-动效三轴系统**（见 §1）。

---

## 0. 上游架构总纲（我们缺的"骨法"）

1. **统一入口 `TokenStepBackdrop(role:)`**（Components.swift:40-60）：全部表面（主窗/浮层/分享卡/截图/Island/更新窗）走同一组件，按 `role` 分发：isInterstellar→InterstellarBackdrop，isVoyage→VoyageBackdropAtmosphere，经典→纯渐变。
2. **表面角色 9 档** `OdysseySurfaceRole`：popover/dashboard/history/privacy/settings/share/update/island/generic（MainWindowView.swift:57-63 把导航 tab 映射为 role）。
3. **按角色 veil**（InterstellarSkin.swift:205-228）：popover 0.16 / dashboard 0.28 / share 0.12 / history 0.43 / privacy 0.52 / settings 0.50 / update 0.42 / island 0.30 / generic 0.36；bottom veil：popover+share 0.22、其余 0.44。
4. **动效三模式**（InterstellarMotionLab.swift:4-70）：quiet 静谧（12fps/星0/无热点）/ orbit 轨道（24fps/星10/有热点）/ gravity_tide 坠落（24fps/星16/热点+推镜）。`ambientIntensity` 0.85/1.0/1.15。
5. **确定性渲染**：`isScreenshotRendering` 冻结动效帧（截图/分享卡）。

## 1. 事件视界体系（Interstellar）

### 层栈（InterstellarSkin.swift:138-190，底→顶）
| # | 层 | 参数 |
|---|---|---|
| 1 | 底色 | `#04070C` |
| 2 | 板图 | Hero/Quiet 按 `usesQuietArtwork`（reduceMotion 或 history/privacy/settings/update 角色 :48），scaledToFill + clipped |
| 3 | 角色 veil | `Color.black.opacity(roleVeilOpacity)` |
| 4 | 热点轨道 | 焊在板图烘焙弧线上，随板缩放（anchor x:0.30,y:0.05） |
| 5 | 视差运动层 | 板缩放的 **1.7 倍**（:200-202），卖纵深 |
| 6 | 对角 scrim | 0.10 → 透明 → 0.62（#04070C） |
| 7 | 底部 veil | center→bottom 渐变 |

### 动效模型（InterstellarMotionLab.swift）
- `InterstellarMotionSample`：primaryPhase/secondaryPhase/starPhase/breath/dollyProgress/hotspotPhase/pulse*。
- **呼吸**：`breath = 0.5+0.5*sin(t*2π/8)`——8 秒周期。
- **推镜（approach，仅 gravity_tide）**：`dollyScale = 1+0.36*pow(progress,1.2)`（:39-41），`dollyBrightness = 0.16*pow(...)`，anchor(0.30,0.05)。
- **热点轨道**（:94-113）：三次贝塞尔 `(0.26,-0.05)→(0.43,0.12)→(0.70,-0.02)→(1.05,0.38)`，沿烘焙弧线游走的亮点。
- **运动层**（:217-252）：暖白光丝带 3 条（宽 0.30-0.50 窗宽、透明度 0.22-0.33×ambientIntensity、blur 0.7-1.8px）横移；1.2px 亮线沿 x 移动（y=0.905）；`warmWhite` 径向渐变（半径 0.36 窗宽）。
- **流星**（:414+）：orbit 10 颗 / gravity_tide 16 颗，`gravity = pow(progress,1.65)` 加速下落，seeded 伪随机。
- **重力脉冲**（gravity_tide 专属）。
- fps：quiet 12 / orbit+坠落 24；低电量再降到 ≤12（Policy:98-104）。

### 面板与饰件
- `InterstellarPanelBackground/InterstellarCardOrnament`（InterstellarSkin.swift:259-364）：1px 发丝描边、0.6px 内高光、绿色渐变边缘辉光（92-128px 宽细线）、定向阴影、弧形/横线饰件。

## 2. 奥德赛体系（Voyage/Odyssey）

### 浮层背景栈（VoyageSkin.swift:297-348）
canvas 底色 → 章节板图 → **火海专属粒子场景** → 左向 scrim（0.04黑/0.08-0.58canvas 四段）→ 顶底 scrim（0.12-0.48）→ **胶片颗粒**。

### 胶片颗粒（OdysseyPopoverFilmTexture :462-479，Canvas 程序化）
23px 网格，`(col*13+row*7)%11==0` 采样；点径 1.3/0.8px；绿 0.10 / 白 0.025 两种。

### 区块面板（OdysseyPopoverSectionBackground :351-372）
canvas 50% 圆角 18 + 1px 发丝（0.86）+ **左上 92×1px 绿色渐变辉光线**（0.56→0.08→透明）+ 阴影(0.22, r14, y7)。

### 特洛伊火焰（OdysseyParticleScene.swift，SpriteKit 584 行）
- **火焰 shader**（:414-445 的 GLSL）：按亮度+暖差提取"热度"图，UV 正弦扰动（`upwardFlow` 周期 108、`sideRipple` 76、时间系数 0.085/5.8）+ 亮度闪烁（`flicker` 7.4Hz、0.055-0.16 增益）——**扰动的是已有板图，不是画新火**。
- **8 个发射器**（:52-58 布局 :338-370，全部以板图比例为坐标）：鬃火(0.62,0.71)/背火(0.42,0.43)/腿火(0.62,0.17)/右火(0.89,0.34)/地火(0.66,0.035)/烟(0.62,0.11)/火星(0.62,0.18)/余烬(0.64,0.25)。
- 诞生率（×intensity）：鬃 7.2/背 5.8/腿 6.8/右 5.8/地 8.4/烟 0.68/火星 6.4/余烬 0.82。
- 火焰粒子：寿命 ~1s±0.22、速度+重力 4、alpha 0.34→关键帧[0,0.38,0.24,0]、add 混合、色序 金橙(0.98,0.63,0.22)→深橙(0.88,0.25,0.06)→暗红透明。
- 火星：速度 72±26、寿命 2.5±0.7、alpha 0.80、scale 0.20。
- 可见性门控：OdysseySurfaceVisibilityReader（NSWindow 可见性 KVO）——"只在真实浮层可见时运行"。

### 章徽章（OdysseySurfaceEmblem :594-609）
矢量浮雕：头盔/木马/神像按章节绘制（directors_cut 按角色选：popover/island→头盔，history/privacy/settings→…），用于浮层/分享卡点缀。

### 品牌联动（TokenStepBrandLockup :253-279）
电影包下标题字距 0.2 + 版本条：`GRAVITY · EVENT HORIZON` 或 `ODYSSEY · DIRECTOR'S CUT` 等（serif 7pt、字距 1.35、greenDark 0.84）+ 12×1px 绿线。`TokenStepMark`（Components.swift:66-76）：事件视界激活时换 `InterstellarTokenStepMark`（程序绘制的吸积盘标志），否则用应用图标。

## 4. 分期计划

### Phase 1「颗粒与面板」——低成本高观感（预计 0.5-1 天）
- A11 胶片颗粒：CSS 程序化背景（重复渐变模拟 23px 网格采样点），皮肤包 body 叠加，透明度 0.025/0.10 分色。`确定性`：静态层，无动画。
- A12 补齐区块面板：左上 92×1px 绿色辉光线（0.56→0.08 渐变）、阴影(0.22/r14/y7)规范到皮肤包所有卡片。
- 验收：实拍对比颗粒质感与面板辉光；经典包零变化。

### Phase 2「动效三模式 + 事件视界完整化」（预计 1-1.5 天）
- A4 动效模式：设置页加"静谧/轨道/坠落"选择（persist 到 settings.json，默认轨道）；映射 fps/星数/热点/推镜开关。
- A3' 呼吸改 8s 周期对齐上游公式；A6 视差光丝带（2-3 条 CSS 渐变条带+blur+横移动画，1.2px 亮线）；A7 流星（canvas 星点，pow1.65 轨迹，数量按模式）；A5 热点（沿贝塞尔曲线的亮点，CSS offset-path）；A8 推镜（仅坠落模式：板图 scale 动画 1→1.36 + 亮度，8s 级周期或滚动触发简化为循环）。
- 验收：三模式实拍对比+FX-CHECK 动画名+低配机器 CPU（任务管理器 <3% 单核）。

### Phase 3「特洛伊火焰完整化」（预计 1-1.5 天）
- A9 火焰 shader 移植：canvas/WebGL 对板图做 UV 扰动+热度闪烁（GLSL 逐行翻译为 WebGL fragment shader，或 canvas 2D 分块位移近似——优先 WebGL，噪声逻辑已在 Swift 里是纯函数）。
- A10 粒子发射器 8 个：JS 粒子引擎（同参数：诞生率/寿命/速度/重力/加色混合/色序），坐标按板图比例定位；可见性门控沿用 IntersectionObserver+document.hidden。
- 验收：火海今日页实拍+动画录屏对比上游 README 描述；CPU 检查；其余章节零变化。

### Phase 4「徽章、品牌与分享卡」（预计 0.5-1 天）
- A13 章徽章 SVG 浮雕（头盔/木马/神像三枚，按上游 VoyageSkin 绘制逻辑移植为 SVG，用于设置页主题卡与隐私卡角落）。
- A14 品牌 version 条（"ODYSSEY · DIRECTOR'S CUT"等）+ 事件视界程序化吸积盘标志替换 header logo。
- A15 分享卡接皮肤：截图导出前按上游"确定性冻结"规则取静态帧（我们截图本来就冻结动效，补板图+veil+颗粒即可）。
- 验收：分享卡导出图检查；品牌条三语不破版。

### Phase 5「可选深水区」（单列，默认不做）
- A17 Token Island：macOS 桌面部件（NSPanel 402+258 行），Windows 等价物需新窗口形态（托盘浮窗），成本高收益存疑——除非你想要。
- 九档 veil 全量数值化：现有观感已验收，改常量有回归风险——仅在 Phase 1-4 完成后若仍有"不像"感再做。

### 每期通用流程
实现 → 只读评审 → cargo build 门 → verify-skins-e2e.ps1 实拍 → 独立验收 agent 判定 → 通过才提交（沿用户已认可的闭环）。

## 5. 风险与边界
- **性能**：粒子+shader 集中在火海一章；事件视界模式粒子 ≤16；全部合成器路径；settings.json 加 `skin_motion_mode`（默认 orbit）。
- **经典包红线**：所有新层挂在 data-skin-pack/chapter 之下；分享卡/经典包路径零接触。
- **资产**：Phase 4 徽章为程序 SVG（上游也是程序绘制，非位图素材），无需新图片。
- **范围外**：Token Island、低电量 API（Windows 无直接等价，用可见性门控替代）。
