# TokenStep 前端重设计参考

本目录记录 0.1.9 前端改版使用的视觉参考与落地说明。

## 参考图

- `tokenstep-ui-gpt-image-2.png`：使用 GPT-Image-2 生成的桌面端 UI 方向稿。

## 方向摘要

- 左侧导航轨道承载今日、历史、隐私和设置，右侧为可滚动工作区。
- 今日页突出每日 Token 进度环，并将额度、趋势、来源/模型拆分和节奏卡片放进清晰的层级系统。
- 蓝紫主色用于进度与导航状态，绿色仅用于本地隐私和成功状态，橙色用于告警。
- 卡片、按钮、导航项、表格行、开关和输入控件均提供 hover / focus-visible 反馈。
- 仅调整前端表现层与版本号，保留现有 Tauri 数据调用、刷新、截图、更新和本地隐私逻辑。

## 生成提示词摘要

使用场景为 `ui-mockup`，目标是 TokenStep Windows 桌面端高保真产品设计板。提示词只提供了真实页面和组件：Today、History/Stats、Privacy、Settings、进度环、额度卡、活动热力墙、趋势图、来源/模型拆分、数据源开关与更新控制；布局、层次、颜色、装饰和交互语言由模型自由发挥。
